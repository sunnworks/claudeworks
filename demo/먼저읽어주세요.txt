약봉투 OCR 기반 농인 대상 수어 복약지도 서비스 — 시연용 데모
==============================================================

[실행 방법]
1. 이 폴더(수어복약지도데모)를 압축 해제한 상태로 둡니다.
2. index.html 을 더블클릭합니다. (Chrome 또는 Edge 권장)
3. "데모계정으로 바로 시작" → "새 복약안내 시작" 순으로 진행합니다.

  * index.html 만 따로 옮기면 수어영상과 약봉투 이미지가 표시되지 않습니다.
    폴더 전체를 함께 보관해 주세요.

[시연 순서]  ── 다음 → 다음 한 줄 흐름입니다
1) "데모계정으로 바로 시작" → "새 복약안내 시작"
2) 약봉투 읽기
   왼쪽에 약봉투 스캔 화면이 뜨고, 읽어온 복약정보와 함께
   "잘 읽혔어요 / 한 번 확인 / 다시 확인" 상태가 표시됩니다.
   → [안내 내용 확인하기]
3) 내용 확인
   빨간색·노란색 항목을 약봉투와 비교해 확인하고, 필요하면 입력창에서 직접 고칩니다.
   항목을 누르면 약봉투에서 해당 위치를 표시해 줍니다.
   → [다음 · 안내 문장 만들기]
4) 안내 문장  ── ① 확인 → ② 추가 두 단계입니다
   ① 만들어진 안내 문장을 확인해 주세요
      만들어진 문장이 모두 [포함하기]로 켜져 있습니다.
      - 순서 바꾸기: 문장의 [위로] / [아래로]를 누릅니다
      - 빼기: [포함하기] 체크를 해제하면 [제외]로 바뀌고 재생되지 않습니다
   ② 덧붙일 주의사항이 있으면 추가해 주세요 (필요할 때만)
      문장 목록 아래의 [＋ 주의사항 안내 추가하기]를 누릅니다.
      - 카테고리 9종: 졸음·운전 / 소화·위장 / 열·통증 / 항생제 /
        술·함께 먹지 않기 / 먹는 방법 / 보관 / 이상반응 / 시간을 놓쳤을 때
      - 미리 만들어 둔 문장 27개에서 골라 [추가]를 누릅니다
      - 검색창에 "졸음", "소화", "보관"처럼 증상·상황을 입력해 찾을 수 있습니다
        (검색할 때는 카테고리 선택과 관계없이 전체에서 찾습니다)
      - 찾는 안내가 없으면 직접 입력 → [수어영상 만들어 추가하기]
        약 1.7초 동안 "수어영상을 만들고 있습니다" 표시가 나온 뒤 문장이 추가되고,
        그 문장은 [약사님이 쓴 문장]으로 표시됩니다
      - 여러 개 추가할 수 있고, 추가한 문장도 5)에서 순서대로 함께 재생됩니다
   오른쪽 "약봉투 내용과 위 문장을 확인했습니다"를 체크한 뒤 진행합니다.
   체크하지 않고 [수어영상 보기]를 누르면 확인을 먼저 해 달라는 안내창이 뜨고,
   [확인란으로 이동]을 누르면 체크란으로 이동합니다.
   → [수어영상 보기]
5) 수어 안내
   [안내 시작]을 누르면 문장마다 수어영상과 자막이 함께 재생됩니다.
   천천히 / 다음 문장 / 이전 문장 / 처음부터를 쓸 수 있습니다.
   약사님이 먼저 확인한 뒤, 들고 있는 패드를 방문자에게 보여주세요.
   → [안내 마치기]
6) 완료
   방문자에게 보여드린 안내를 확인하고 → [안내 마치고 다시보기 QR 만들기]
   QR과 함께 "48시간 동안 다시 볼 수 있습니다", 볼 수 있는 기한이 표시됩니다.
   설명할 때: "방문자는 이 QR로 48시간 동안 같은 안내를 다시 볼 수 있고,
   그 뒤에는 자동으로 지워집니다"라고 안내하시면 됩니다.
   → [다른 약봉투 예시 해보기]
7) 약봉투 예시 목록
   다른 양식으로 같은 흐름을 이어서 해볼 수 있습니다. 해본 예시에는 "해봤어요"가 표시됩니다.

[약봉투 예시 6종]
- 감기 (일반 약봉투)        : 다 읽혀서 바로 안내까지 진행되는 흐름
- 표 인쇄 (표로 인쇄된 약봉투) : 단위와 먹는 시점을 약사가 확인해야 하는 흐름
- 통증 (증상 있을 때 먹는 약) : 정해진 시간 약과 따로 안내하는 흐름
- 사진 흐림 (흐리게 찍힌 약봉투) : 다시 찍어야 하는 흐름
- 불면 (빛이 반사된 약봉투)  : 하루 몇 번이 잘 안 읽혀 고쳐야 하는 흐름
- 손글씨 (손으로 적은 약봉투) : 글자를 거의 못 읽어 처음부터 직접 입력하는 흐름

[실제 약봉투 없이 촬영 동작을 보여주려면]
- 대시보드의 "시연용 약봉투 인쇄"에서 A4 배율 100%로 출력하거나,
  samples/bag-table.png (표 양식) / samples/bag-regular.png (라벨 양식)을 인쇄합니다.
- 촬영 화면에서 "촬영 이미지에 적용할 시연 케이스"를 먼저 지정한 뒤
  - 휴대기기: "휴대기기 카메라로 촬영" → 카메라 앱으로 인쇄물 촬영
  - PC: "사진 불러오기" → 미리 찍어둔 사진 선택
  촬영한 사진이 원문 이미지로 들어가고 지정한 케이스의 인식 결과가 적용됩니다.

[카메라가 안 켜지는 이유]
브라우저는 보안 정책상 카메라 미리보기(getUserMedia)를 https 주소 또는 localhost에서만
허용합니다. 로컬 파일(index.html)로 열면 차단되므로, 위의 "휴대기기 카메라로 촬영" 또는
"사진 불러오기"를 사용하세요. 실제 카메라 미리보기가 필요하면 저장소 코드를 https로
배포해 접속해야 합니다.

[중요한 안내]
- 모든 환자·의약품 정보는 시연용 가상 데이터입니다. 실제 처방이 아닙니다.
- 수어영상은 데모용 샘플이며 자막 내용과 일치하지 않습니다.
  KLcube 아바타 API 연동 시 승인된 문장에 맞는 수어가 생성됩니다.
- 이 데모는 질환을 추정하거나 복용법을 자동 생성하지 않으며,
  약사가 최종 승인한 내용만 전달합니다.
- 수어 아바타 안내만으로 법정 복약지도 의무가 충족된다고 전제하지 않습니다.
- 이 로컬 데모는 서버 없이 브라우저에서만 동작합니다. 브라우저를 닫으면
  세션과 QR 정보가 사라집니다.
- 수어영상 5개는 화면을 열 때 미리 받아 두고 같은 영상 요소를 계속 다시 씁니다.
  그래서 [안내 시작]과 [다음 문장]에서 영상이 바로 시작됩니다.
  (측정값: 첫 프레임까지 32ms, 문장 전환 32ms)
  영상이 아직 준비되지 않은 동안에는 자막과 진행바도 함께 기다리므로
  자막이 영상보다 앞서 나가지 않습니다.
- 이 기기에서 mp4를 재생할 수 없으면 그림 아바타와 수어 순서 표시로 자동 전환됩니다.
- 방문자가 버튼으로 질문을 보내는 기능은 이 데모에서 제외했습니다.

[QR 다시보기]
QR은 앱 안에서 직접 만들어 그립니다(외부 인터넷 연결이 필요하지 않습니다).
화면에는 48시간 동안 다시 볼 수 있다는 안내와 기한이 표시됩니다.

- 파일로 열었을 때는 QR 주소가 내 컴퓨터 경로이므로 휴대전화로 스캔해도 열리지 않습니다.
  이때는 [다시보기 화면 열어보기] 버튼으로 같은 화면을 보여주세요.
- 실제로 휴대전화 스캔까지 시연하려면 저장소 코드를 https 주소로 배포해야 합니다.
- 48시간 경과 후 자동 삭제는 서버형 구현(저장소 코드)에 들어 있고, 단위테스트로
  발급 직후 / 47시간 59분 / 정확히 48시간 / 48시간 이후를 검증해 두었습니다.
