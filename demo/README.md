# 약사용 수어 복약지도 시연 앱 (단일 파일)

`index.html` 하나로 동작하는 시연용 앱입니다. 서버도, 인터넷 연결도 필요하지 않습니다.
같은 폴더에 `avatar-samples/`(수어영상 샘플 5개)와 `samples/`(약봉투 예시 이미지)가 있어야
영상과 약봉투가 표시됩니다.

## 배포용 ZIP 만들기

```bash
./scripts/build-demo-zip.sh
# → dist/수어복약지도데모.zip
```

## 시연 흐름

약봉투 읽기 → 내용 확인 → 안내 문장(① 확인 → ② 주의사항 추가) → 수어 안내 → 완료(48시간 다시보기 QR)

자세한 진행 순서와 시연 멘트는 `먼저읽어주세요.txt`에 있습니다.

## 구현 메모

- **수어영상 재생 지연**: 화면을 열 때 샘플 영상 5개를 `preload="auto"`로 미리 받아
  숨은 보관함(`#vwarm`)에 두고, 재생할 때 같은 `<video>` 요소를 무대로 옮겨 붙인다.
  화면을 다시 그릴 때(`render()`)는 먼저 `parkVideos()`로 요소를 보관함에 되돌려
  `innerHTML` 교체에 지워지지 않게 한다. 진행바와 자막은 `video.currentTime`을 따라가고,
  영상이 준비되지 않은 동안(`readyState < 3`)에는 함께 기다린다.
  측정값: 첫 프레임까지 32ms, 문장 전환 32ms.
- **mp4를 못 여는 기기**: 미리 받는 단계에서 생긴 오류까지 잡아 그림 아바타와
  수어 순서 표시로 자동 전환한다.
- **QR**: 외부 라이브러리 없이 ISO/IEC 18004 Model 2(바이트 모드, 오류정정 L, 버전 1~10)를
  직접 구현해 SVG로 그린다.
- **주의사항 안내 추가**: 카테고리 9종 · 검수 문구 27개에서 고르거나 직접 입력한다.
  직접 입력한 문장은 `약사님이 쓴 문장`으로 표시하고 수어영상을 새로 만들어 붙인다.
- 모든 데이터는 시연용 가상 데이터이며, 수어영상은 자막 내용과 일치하지 않는 샘플이다.
