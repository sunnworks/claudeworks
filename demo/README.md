# 약사용 수어 복약지도 시연 앱 (단일 파일)

`index.html` 하나로 동작하는 시연용 앱입니다. 서버도, 인터넷 연결도 필요하지 않습니다.
같은 폴더에 `avatar-samples/`(수어영상 샘플 5개)와 `samples/`(약봉투 예시 이미지)가 있어야
영상과 약봉투가 표시됩니다.

## 자체완결 index.html

배포용 `index.html` 은 수어영상 5개와 약봉투 예시 이미지를 data URI로 품고 있어
외부 파일이 필요 없다. 휴대전화·태블릿의 파일 관리자가 HTML을 `content://` 주소로
띄우면 같은 폴더의 mp4를 찾지 못해 수어영상이 그림 아바타로 대체되는데, 매체를
파일 안에 심어 두면 어떤 방식으로 열어도 그대로 재생된다.

```bash
node scripts/build-standalone.mjs dist/index.html   # 약 4.3MB
```

저장소의 `demo/index.html` 은 상대 경로를 쓰는 원본이고(Artifact 배포용),
위 스크립트가 `public/avatar-samples` 와 `public/samples` 를 읽어 심는다.

## 파일 이름 규칙

배포용 ZIP 안의 이름은 전부 영문으로 둔다. ZIP 규격은 파일명 인코딩을 헤더 플래그로만
알리는데, `zip`이 한글 이름을 UTF-8로 저장하면서 그 플래그를 세우지 않으면 Windows
탐색기가 CP949로 해석해 이름이 깨지고 압축이 제대로 풀리지 않는다. 이름에 한글이
없으면 어떤 압축 프로그램에서도 같은 결과가 나온다.

## 배포용 ZIP 만들기

```bash
./scripts/build-demo-zip.sh
# → dist/수어복약지도데모.zip
```

## 사용 설명서

`demo/USER-MANUAL.pdf` (A4 42쪽) — 압축 풀기부터 시연 마무리까지, 화면 캡처 30장과 함께
단계별 사용법, 시연 멘트, 문제 해결 방법을 담았습니다. 배포용 ZIP에도 함께 들어갑니다.

원본은 `demo/manual/사용설명서.html` 이고, PDF는 이렇게 다시 만듭니다.

```bash
node scripts/build-manual-pdf.mjs        # → demo/USER-MANUAL.pdf
```

한글 본문은 `demo/manual/fonts` 의 Noto Sans KR(woff2)을 `@font-face`로 심어 씁니다.
PDF 생성 라이브러리의 내장 폰트에는 한글 글리프가 없어 HTML → Chromium 방식을 씁니다.

## 시연 흐름

약봉투 읽기 → 내용 확인 → 안내 문장(① 확인 → ② 주의사항 추가) → 수어 안내 → 완료(48시간 다시보기 QR)

자세한 진행 순서와 시연 멘트는 `HOW-TO-START.txt`에 있습니다.

## 구현 메모

- **수어영상 재생 지연**: 화면을 열 때 샘플 영상 5개를 `preload="auto"`로 미리 받아
  숨은 보관함(`#vwarm`)에 두고, 재생할 때 같은 `<video>` 요소를 무대로 옮겨 붙인다.
  화면을 다시 그릴 때(`render()`)는 먼저 `parkVideos()`로 요소를 보관함에 되돌려
  `innerHTML` 교체에 지워지지 않게 한다. 진행바와 자막은 `video.currentTime`을 따라가고,
  영상이 준비되지 않은 동안(`readyState < 3`)에는 함께 기다린다.
  측정값: 첫 프레임까지 32ms, 문장 전환 32ms.
- **mp4를 못 여는 기기**: 미리 받는 단계에서 생긴 오류까지 잡아 그림 아바타와
  수어 순서 표시로 자동 전환한다.
- **QR**: 외부 라이브러리 없이 ISO/IEC 18004 Model 2(바이트 모드, 오류정정 L, 버전 1~10)를
  직접 구현해 SVG로 그린다.
- **주의사항 안내 추가**: 카테고리 9종 · 검수 문구 27개에서 고르거나 직접 입력한다.
  직접 입력한 문장은 `약사님이 쓴 문장`으로 표시하고 수어영상을 새로 만들어 붙인다.
- 모든 데이터는 시연용 가상 데이터이며, 수어영상은 자막 내용과 일치하지 않는 샘플이다.
